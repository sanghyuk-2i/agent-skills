# 프레임 규격 (고정)

모든 어노테이션 이미지는 아래 규격을 따른다. 레포별 설정으로 바꾸지 않는다 — 팀 안에서 이미지 모양이 갈라지지 않게 하기 위해서다.
값의 원본은 `scripts/render.mjs`의 `stageHtml`이며, 이 문서와 어긋나면 이 문서가 기준이다.

텍스트는 **번호와 `BEFORE`/`AFTER` 라벨뿐**이다. 제목·소제목·설명문을 이미지에 굽지 않는다. 박스별 설명은 PR 본문 텍스트에서 번호로 연결한다.

## 박스

| 항목 | 값 |
|---|---|
| 선 색 | `#ff2d55` |
| 선 굵기 | 4px (실선) |
| 모서리 | 4px |
| 바깥 후광 | 흰색 2px + `rgba(255,45,85,.18)` 6px |
| 위치 | 변경 영역 좌표 그대로. 박스를 키우거나 여백을 주지 않는다 |

## 번호 뱃지

| 항목 | 값 |
|---|---|
| 모양 | 지름 40px 원형 (숫자가 두 자리면 가로로 늘어남, `min-width: 40px`) |
| 배경 / 글자 | `#ff2d55` / `#fff`, 24px, 굵기 600 |
| 위치 | 박스 좌상단에서 (-18px, -18px) |
| 번호 | 1부터, 읽는 순서: 위→아래, 높이 차이가 페이지 높이의 2% 이내인 박스끼리는 왼→오. before와 after에서 같은 박스는 같은 번호 |

## 프레임 (전/후 비교)

| 항목 | 값 |
|---|---|
| 구성 | 왼쪽 `BEFORE`, 오른쪽 `AFTER` 두 패널을 가로로 나란히 |
| 패널 간격 | 32px |
| 라벨 | 패널 위, 배경 `#111` / 글자 `#fff`, 28px, 굵기 600, 패딩 10px 20px, 모서리 8px |
| 패널 테두리 | 1px `#e5e5e5` |
| 배경 | `#fff` |
| 박스 | **양쪽 패널 모두**에 같은 좌표·같은 번호로 그린다 |

## 산출물 종류

| 파일 | 내용 |
|---|---|
| `<name>.sidebyside.png` | 위 프레임 전체. PR에 기본으로 쓰는 이미지 |
| `<name>.before.annotated.png`, `<name>.after.annotated.png` | 라벨 없이 박스만 그린 단일 패널 |
| `<name>.box-N.png` | 박스 N의 크롭 (BEFORE/AFTER 라벨, 패딩 24px, 패널 간격 16px, 라벨 높이 28px). 설명을 쓰기 위해 눈으로 확인하는 용도 |

박스도 없고 `wholePageChanged`도 아니면 어노테이션 이미지는 만들지 않는다(`renderSkipped: true`).
`wholePageChanged`면 박스 없이 `BEFORE`/`AFTER` 프레임만 만든다.
