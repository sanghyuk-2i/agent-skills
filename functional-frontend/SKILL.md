# 함수형 프론트엔드

전체 워크플로우(0~5단계, 리팩토링 모드, 셋업 모드, 참고 문서)는 이 디렉터리의 [`AGENTS.md`](./AGENTS.md)에 있다. **그 문서를 읽고 순서대로 따른다.** Claude Code 전용으로 바뀌는 부분은 없다 — 도구 이름을 언급하지 않는 순수 워크플로우이므로 AGENTS.md를 그대로 실행하면 된다.

레퍼런스 문서(`references/*.md`), ESLint 프리셋(`eslint/`), 템플릿(`assets/`)은 AGENTS.md에서 지칭하는 그대로 이 디렉터리 안에 있다.
